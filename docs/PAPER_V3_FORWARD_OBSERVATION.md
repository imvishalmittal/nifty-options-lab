# NIFTY Paper Forward Observation: V2 + V3

The weekday paper session intentionally observes three strategies on the same market-data cohort:

- **V2:** ₹180 crossing family, ₹160 initial stop, ₹220 activation, continuous 20-point causal trail.
- **V3-5:** same entry/contract selection, stepped 5-point trail.
- **V3-10:** same entry/contract selection, stepped 10-point trail.

All variants share the same NIFTY signal, selected weekly contract, side, next-bar entry, lot count, completed 1-minute candles, ₹60,000 model capital, and no-overnight/no-broker execution. They are recorded as separate PAPER rows so outcomes can be compared without cohort drift.

This is an observation configuration only. It does not change historical research conclusions or select a trading rule from future observations.
